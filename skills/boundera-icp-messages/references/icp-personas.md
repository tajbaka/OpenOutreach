# Boundera ICP Persona Angles

This is a human-maintained strategy reference for ICP Messages Sheet copy. It
must not contain deployed message text, dates, program-status claims, or copied
rows from `linkedin/icp_messages.json`.

Use one primary persona per message variant. The `What matters most` and
`Attention angle` entries are hypotheses for writing, not facts about a named
recipient. Personalize only from verified profile, company, campaign, or
conversation evidence.

## Cloud Service Providers

| Persona | Common Sheet ICP labels | What matters most | Attention angle |
| --- | --- | --- | --- |
| Founder / CEO | `CSPs`, `CSP Stage Verify`, `20x Initial Implementation`, `Active FedRAMP Path` | Federal-market access, execution risk, internal ownership, and avoiding an open-ended compliance effort | Connect FedRAMP execution to a clearer operating path without leading with technical detail |
| CFO / Finance | `CSPs`, `Active FedRAMP Path`, `FedRAMP Mature` | Budget predictability, internal headcount, outside-services spend, and the timing of federal revenue | Focus on making evidence, review, and remediation work more predictable; never assert savings or budget pressure without proof |
| CISO / Security leader | `CSPs`, `20x Initial Implementation`, `Active FedRAMP Path`, `FedRAMP Mature` | Credible security outcomes, risk visibility, ownership of gaps, and confidence in what is being presented for review | Lead with seeing whether measures are working and where evidence or remediation is falling behind |
| GRC / FedRAMP program owner | `CSPs`, `20x Initial Implementation`, `Active FedRAMP Path`, `Rev5 Ready`, `FedRAMP Mature` | Measures, evidence completeness, package maintenance, assessor coordination, and day-to-day program control | Lead with traceability among implementation, evidence, validation, findings, and current certification data |
| CTO / VP Engineering | `CSPs`, `20x Initial Implementation`, `Active FedRAMP Path` | Engineering capacity, production ownership, integration burden, and avoiding compliance work that is detached from real systems | Lead with evidence at the source, repeatable validation, and remediation routed to the responsible technical owner |
| DevSecOps / Cloud security | `CSPs`, `20x Initial Implementation`, `FedRAMP Mature` | Reliable checks, implementation drift, actionable findings, and minimal manual evidence handling | Lead with visible measure failures and evidence generated from authoritative implementation sources |

## Maintenance Rules

- Add a persona only when it changes the message angle materially.
- Keep each cell to one sentence where possible.
- Do not add actual connection notes, follow-ups, email copy, or booking links.
- Do not encode a current FedRAMP deadline or rule status here.
- Keep draft copy in `General ICP Messages`; explicitly import reviewed copy to
  the checked-in JSON stores, then let campaign creation snapshot that JSON as
  an immutable SQL version frozen per Deal.
- CMMC personas require their own current regulatory and product grounding; do
  not derive them from the FedRAMP 20x references.
